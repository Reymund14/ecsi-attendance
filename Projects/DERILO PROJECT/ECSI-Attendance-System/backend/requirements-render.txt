# ECSI Attendance System — Render (cloud) dependencies
#
# Deliberately EXCLUDES OpenCV / DeepFace / TensorFlow / ONNX (~1.5 GB).
# Render cannot reach a physical camera or RFID reader, so the cloud service
# never opens a capture device: all camera frames are produced in the browser
# and POSTed in as base64 (see frontend/index.html -> processFrame).
#
# services/face_service.py imports cv2/numpy/DeepFace lazily and inside
# try/except, so main.py still starts cleanly without them. Face *enrollment*
# is the one endpoint that will return 503 in the cloud; everything else
# (auth, RBAC, attendance, reports, WebSocket dashboard) works normally.
#
# Use this file for Render. Use requirements.txt for local/edge hardware work.
# ─────────────────────────────────────────────────────────────────────────────
